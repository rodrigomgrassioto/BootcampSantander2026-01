## 👋 Sobre este repositório

Este repositório reúne o material prático desenvolvido ao longo do **Bootcamp Santander 2026**.

Mais do que um conjunto de exercícios, ele representa uma trilha de evolução: os primeiros conteúdos trabalham fundamentos da linguagem e orientação a objetos; os conteúdos seguintes avançam para boas práticas, persistência, Spring, Design Patterns e, finalmente, integração de aplicações Java com **Inteligência Artificial e processamento de áudio**.

A organização foi mantida de forma que cada aula, exercício ou projeto possa ser estudado isoladamente, mas a recomendação é **baixar/clonar o portfólio completo** e, depois, executar somente o conteúdo de interesse.

### 🎯 Competências demonstradas

- ☕ Java e Programação Orientada a Objetos
- 🧩 Classes, encapsulamento, herança e polimorfismo
- 🏷️ Annotations e recursos avançados da linguagem
- 🧱 SOLID e boas práticas de design
- 🏗️ Design Patterns
- 🔗 Interfaces, Lambda e Collections
- 🗄️ MySQL, JPA e persistência
- 🌱 Spring Framework e Spring Boot
- 🌐 APIs REST
- 🧪 Testes e integração
- 🤖 Spring AI e integração com LLMs
- 🛠️ Tool Calling
- 🎙️ Whisper / Speech-to-Text
- 🔊 Text-to-Speech
- 📐 Organização arquitetural e separação de responsabilidades

## 🤖 612 — Budgeting Project com Inteligência Artificial

### Projeto final do portfólio

Uma API inteligente de controle financeiro construída com **Spring Boot + Spring AI**, combinando processamento de linguagem natural, Tool Calling, transcrição de áudio, Text-to-Speech e persistência em MySQL.

O projeto recebe comandos em linguagem natural — inclusive por voz — e conecta a interpretação feita pela IA com **operações reais de negócio**.

### 🔄 Fluxo principal

```text
🎙️ Usuário
   ↓
🎧 Áudio
   ↓
Whisper / Speech-to-Text
   ↓
📝 Texto
   ↓
🧠 Spring AI / LLM
   ↓
🛠️ Tool Calling
   ↓
PersistTransactionUseCase
   ↓
Transaction
   ↓
🗄️ MySQL
   ↓
🧠 Resposta do LLM
   ↓
🔊 Text-to-Speech
   ↓
🎧 Resposta em áudio
   ↓
👤 Usuário
```

### 🧠 O que o projeto demonstra

- Spring Boot
- Spring AI
- `ChatClient`
- `ChatModel`
- Tool Calling
- Casos de uso de negócio
- JPA / Hibernate
- MySQL
- API REST
- Whisper / Speech-to-Text
- Text-to-Speech
- Testes de integração
- Separação entre Domain, Application e Infrastructure

# 💻 Como utilizar o portfólio

## 1. Clone ou baixe o repositório completo

A recomendação é **baixar/clonar o portfólio inteiro**, em vez de tentar instalar cada aula separadamente.

```bash
git clone https://github.com/rodrigomgrassioto/BootcampSantander2026-01.git
```

Depois:

```bash
cd BootcampSantander2026-01
```

> Se o diretório local possuir outro nome, utilize o nome gerado pelo Git ao clonar o repositório.

## 2. Escolha o conteúdo que deseja executar

Cada exercício ou projeto possui sua própria estrutura e pode ter requisitos específicos.

Por exemplo, para o projeto final:

```bash
cd Projetos/612-budgetingProjFinalComIA
```

Depois consulte o README correspondente para verificar:

- requisitos;
- versão do Java;
- banco de dados;
- variáveis de ambiente;
- serviços externos;
- comandos de execução;
- testes.

## 3. Não é necessário instalar tudo

O portfólio contém diferentes projetos e etapas do Bootcamp. **Instale e configure somente aquilo que deseja estudar ou executar.**

Isso evita transformar o repositório inteiro em uma única aplicação e mantém cada projeto independente.

# 🏆 Destaques do portfólio

### 🧩 Do conceito à implementação

Os exercícios mostram a evolução dos conceitos fundamentais de Java antes dos projetos mais completos.

### 🏗️ Aplicação de boas práticas

SOLID, Design Patterns, separação de responsabilidades e organização arquitetural aparecem progressivamente no código.

### 🤖 IA conectada a negócio real

O Projeto 612 demonstra uma etapa mais avançada: o LLM não é utilizado somente para gerar respostas. Ele pode **interpretar uma intenção e acionar ferramentas que executam operações reais da aplicação**.

### 🎙️ Experiência multimodal

O projeto final também conecta **voz → texto → IA → operação → resposta → voz**, demonstrando uma integração prática entre backend e serviços de Inteligência Artificial.
